# Zapret Hub 0.1.5

Главное обновление после версии `0.1.4`: приложение стало быстрее закрываться, а подбор рабочего профиля теперь полностью выполняется внутри понятного графического интерфейса.

## Что изменилось

- Bundle обновлён до `zapret-discord-youtube 1.10.0`, Telegram WS Proxy — до `v1.9.1`.
- Поиск лучшего профиля перенесён из отдельного окна PowerShell в Zapret Hub.
- Во время поиска отображаются текущий профиль, этап проверки, общий прогресс и кнопка отмены.
- Добавлен расширенный поиск: обычная HTTP/TLS/ping-проверка, режим DPI 16–20 КБ и выбор отдельных профилей.
- Результаты выводятся таблицей; найденный профиль можно сразу сделать основным.
- Поддерживается новый профиль `general (EXP).bat` — всего в комплекте 21 профиль.
- В разделе профилей появился отдельный выбор UDP fake-файлов для Discord Voice и GameFilter.
- Закрытие приложения и остановка runtime стали быстрее: процессы и службы завершаются вместе с общим лимитом ожидания восемь секунд.
- Уменьшена фоновая нагрузка при проверке запущенных процессов.
- Обновление через установщик и встроенный механизм сохраняет пользовательские списки, активные UDP fake-файлы, состояние Game Filter и диагностические логи.
- Установщик и release-скрипты используют закреплённые версии upstream, поэтому содержимое сборки воспроизводимо.

## Состав релиза

- Установщик: `zapret-hub-setup-0.1.5.exe`
- Манифест обновления: `latest.json`
