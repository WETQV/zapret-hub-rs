# Telegram CF media

`CF media` режим нужен для случая, когда Telegram Desktop получает сообщения, но фото, видео, реакции или часть файлов не загружаются.

Режим использует `TG WS Proxy` и ваш домен в Cloudflare. Общий домен в приложении намеренно не задан: один публичный домен быстро становится узким местом, потому что Telegram открывает много WebSocket-соединений.

## Что нужно

- Полностью управляемый домен, который можно добавить в Cloudflare.
- Бесплатный план Cloudflare подходит.
- Возможность поменять NS-серверы у регистратора домена.
- Включённый профиль `zapret` в Zapret Hub.

Обычные Dynamic DNS-субдомены не подходят. Нужен домен, который Cloudflare обслуживает в режиме `Full setup`.

## Настройка Cloudflare

1. Добавьте домен в Cloudflare через `Add a domain`.
2. Выберите план `Free`.
3. Дождитесь, пока Cloudflare выдаст два nameserver.
4. У регистратора домена замените текущие NS на nameserver от Cloudflare.
5. Дождитесь статуса `Active` в Cloudflare.
6. В `SSL/TLS -> Overview` выставьте режим `Flexible`.
7. В `Network` проверьте, что `WebSockets` включены.

## DNS-записи

В Cloudflare откройте `DNS -> Records` и добавьте `A`-записи с включённым proxy, то есть с оранжевым облаком.

| Name | IPv4 |
| --- | --- |
| `kws1` | `149.154.175.50` |
| `kws2` | `149.154.167.51` |
| `kws3` | `149.154.175.100` |
| `kws4` | `149.154.167.91` |
| `kws5` | `149.154.171.5` |
| `kws203` | `91.105.192.100` |

## Настройка Zapret Hub

1. Остановите текущий профиль.
2. Включите галочку `Telegram proxy`.
3. Выберите режим `CF media`.
4. Введите свой домен, например `example.ru`, без `https://` и без `kws1`.
5. Запустите основной профиль.

Zapret Hub сам добавит домен и `kws1/kws2/kws3/kws4/kws5/kws203` в пользовательский hostlist `zapret`. Также приложение синхронизирует конфиг `TG WS Proxy` и оставит для `CF media` только `DC4`, как рекомендует upstream для проблемы с медиа.

## Проверка

В окне `TG WS Proxy` должно быть видно:

- `CF-прокси` включён.
- Домен равен вашему домену.
- В `DC->IP` для `CF media` остался только `4:149.154.167.220`.

Если что-то не работает, откройте лог `TG WS Proxy` через tray-меню. В нормальном случае там должны появляться подключения к `kws*.ваш-домен`.

## Ограничения

`CF media` не гарантирует загрузку всех медиа во всех чатах. По upstream `tg-ws-proxy`, часть Telegram-трафика может идти через другие DC, где этот обход не помогает. Звонки и голосовые тоже не считаются гарантированно исправленными.

Один общий Cloudflare-домен лучше использовать только для теста и маленького личного круга. Для стабильной работы каждому пользователю или небольшой группе стоит завести свой домен.
