# Zapret Hub 0.1.6

Небольшой стабилизационный релиз после `0.1.5`. Главное изменение — свёрнутый или запущенный через автозагрузку GUI теперь можно вернуть обычным повторным запуском приложения.

## Что изменилось

- Повторный запуск Zapret Hub теперь восстанавливает уже открытое окно и выводит его на передний план вместо сообщения без возможности вернуться в GUI.
- Исправлен сценарий автозапуска, при котором процесс продолжал работать, но свёрнутое окно было трудно найти в панели задач.
- Отсутствующая служба `zapret` теперь корректно определяется по выводу `sc` в stderr и отображается как неустановленная.
- Тест профилей можно запускать, когда служба `zapret` установлена, но остановлена; удалять службу перед тестом больше не требуется.
- Обновлён `Cargo.lock` до актуальных совместимых с Rust 1.94 версий библиотек, включая сетевой, TLS- и Windows-стек.
- Bundle остаётся на закреплённой версии `zapret-discord-youtube 1.10.0`, Telegram WS Proxy — на `v1.9.1`.

## Состав релиза

- Установщик: `zapret-hub-setup-0.1.6.exe`
- Манифест обновления: `latest.json`
