# Zapret Hub 0.2.0

Большое обновление: новый интерфейс, иконка в трее, рабочее обновление bundle в один клик и сборка под Windows прямо с Linux.

## Интерфейс

- Новый дизайн: боковое меню, большая кнопка включения на главной, переключатели вместо чекбоксов, всплывающие уведомления и журнал событий.
- Светлая и тёмная тема переключаются вслед за Windows.
- Убраны дубли: запуск, Telegram proxy и обновления больше не повторяются на нескольких вкладках.
- Если после смены профиля или опций нужно перезапустить обход, на главной появляется кнопка «Перезапустить».
- Подбор профиля показывает текущую проверку, лидера на данный момент и таблицу результатов с полосками.

## Окно

- Собственная шапка окна: свернуть, развернуть, закрыть, перетаскивание и двойной клик; изменение размера за края.
- Плавные анимации: переход между страницами, скользящая подсветка в меню, появление уведомлений, наведение на кнопки.

## Telegram

- Прокси Flowseal теперь MTProto на порту 1443; настройка `config.json` приведена к новому формату (раньше записывались порт 1080 и устаревшие ключи, из-за чего режим CF media не работал).
- Лишние ключи конфига пользователя сохраняются, зашитый в программу секрет убран.
- Кнопки «Открыть в Telegram» и «Скопировать ссылку» с готовой `tg://proxy` ссылкой.
- Ссылки в программе открываются корректно и в snap-браузерах на Linux.

## Трей

- Иконка в трее: серая — обход выключен, цветная — включён. Меню: открыть, включить/выключить, выход.
- Крестик сворачивает окно в трей, обход продолжает работать (можно выключить в настройках).
- Автозапуск стартует сразу в трей и при желании сразу включает основной профиль.
- Повторный запуск exe показывает окно уже работающего экземпляра, даже если оно спрятано в трее.

## Исправления

- **Кнопка обновления bundle снова работает.**
  - «Позже» больше не блокирует кнопку скачивания навсегда.
  - Bundle готовится рядом с текущим, а не в `%TEMP%`: переименование между дисками раньше падало у портативных установок на D:.
  - Если папку bundle держит Проводник или антивирус, файлы заменяются на месте с резервной копией и откатом.
  - Распаковка — без PowerShell.
  - Обход останавливается и запускается снова автоматически, служба `zapret` тоже возвращается.
- При лимите GitHub API (60 запросов в час) проверка обновлений переключается на github.com.
- **Больше не появляются окна консоли.**
  - Upstream-профили 1.10.x запускали `winws.exe` через `start /min`, и в панели задач висело свёрнутое окно. Профиль теперь патчится перед каждым запуском, а не только при обновлении.
  - Проверки curl и прав администратора перед подбором профиля выполняются скрыто и не подвешивают интерфейс.
- Статус процессов и служб читается напрямую через WinAPI вместо `tasklist`/`sc` каждые две секунды; в простое интерфейс не перерисовывается.
- Подбор профиля останавливает `winws.exe` между профилями. Раньше со второго профиля замеры шли при двух одновременно запущенных winws.
- Строки-комментарии из `utils\targets.txt` больше не превращаются в цели теста.
- `pause` в upstream-скриптах больше не может навсегда подвесить скрытый запуск.
- Если winws не стартовал, показывается понятная причина (служба или антивирус).
- Остановка выгружает драйвер WinDivert, чтобы `WinDivert64.sys` не держал файлы bundle.
- Убран зашитый путь `C:\Users\mejik\Downloads\...`. Без bundle приложение предлагает скачать его.
- Настройки сохраняются атомарно.
- Деинсталлятор удаляет задачу автозапуска.

## Зависимости и сборка

- eframe/egui 0.33 → 0.37, reqwest 0.12 → 0.13 (schannel на Windows), sha2 0.10 → 0.11, winres → winresource. Добавлены tray-icon и zip.
- Сборка под Windows с Linux: `packaging/build-windows.sh` (mingw-w64). Иконка и манифест теперь встраиваются и при кросс-сборке.
- Bundle для релиза собирается тем же кодом, что и обновление в приложении (`--stage-bundle`). Около 700 строк дублирующего PowerShell удалены, версия bundle больше не закреплена на 1.10.0.

## Состав релиза

- Bundle `zapret-discord-youtube 1.10.4`, Telegram WS Proxy `v1.11.2`
- Портативный архив: `zapret-hub-0.2.0-portable.zip`
- Установщик: `zapret-hub-setup-0.2.0.exe` (собирается на Windows через Inno Setup)
